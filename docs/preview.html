四种尺寸

1×1 · 专注小格

只有图形，没有字

一格最多 60–90dp，放文字就得压到 11sp 以下。这一版干脆只留人像，图形自己说明用途，点整格直接进。

1×1 · 屏幕用时

靠图形区分

同样不带文字，用时钟和人像区分两个 1×1。点一下进「屏幕使用时间」，看今天到底用了多久。

2×2 · 专注入口

一张小海报，只有人像

淡蓝渐变卡 + 头部后方一团柔光，安全区内等比撑满：110dp 的最小格子里人像约 78dp，常见的 180dp 格子里能到 148dp。整块可点。

4×2 · 专注与屏幕时间

左右两块，各管一件事

474dp 宽的卡片里，左边改成「人像 + 文案」横排（人像占四成宽、高度撑满），右边时钟竖排。两个热区互不干扰。

加到桌面的正确路径

搜索框里搜「静叶」是搜不到的

长按桌面空白处 → 添加小组件 → 全部应用 → 安卓小部件 → 拉到最下方

侧载应用的组件不在小米小部件中心的索引里，这是澎湃 OS 的限制，不是组件没装上。 在「安卓小部件」列表的最下方能看到「专注入口」「专注小格」「屏幕用时」「专注与屏幕时间」四个， 长按任意一个拖到桌面即可。装完第一次打开「静叶」时，应用里的引导页也写了这条路径。

图标与控制中心

桌面图标：自适应图标，带主题单色层
控制中心磁贴：浅色界面深墨剪影、深色界面白剪影，系统着色也不会翻车

抠图这一步做了什么

你抠的那张图比原来干净得多，只差两处：左上角一截工具栏、右下角一个水印， 而且边缘留了一圈半透明白描边。这两处靠「取最大连通域」直接出局， 描边靠「最近邻颜色向外扩散」洗掉，落在蓝底上才不会泛出一圈白毛。

说明

01 / 为什么能点

直接拉起系统页面

com.xiaomi.misettings/.usagestats.FocusSettingsMainActivity 对外导出，组件用 PendingIntent 直达；失败时依次回退到屏幕时间页、系统设置。

02 / 磁贴图标

这次修好了

旧版磁贴图标是矢量图，路径里漏了 fillColor，渲染出来是空的——所以只有字没有图。现在按密度出位图剪影，纯白单色，颜色由系统着色。

03 / 图标来源

用你抠好的那张，再修一遍边

那张 PNG 其实是不透明的白底，左上角还留着一截工具栏、右下角有个水印。按「近白即背景」取最大连通域，两块残片直接出局；再把边缘那圈半透明白描边用「最近邻颜色向外扩散」洗掉，落在蓝底上才不泛白毛。

04 / 仍然要说

时长还得自己选

系统没有公开「带时长直接开始」的接口，组件只把四步路径压成一步；专注开始后中途退不出，这是系统行为。
